## 三、提交到牛客时注意

1. **语言选 Python 3**（题目说明语言不限；若课程要求 C/C++，把同一份逻辑改写即可，每题注释里都写了思路）。
2. 每个文件是**完整可提交程序**：包含 `main()` 与 `if __name__ == "__main__":`，直接全选粘贴。
3. 输入一律用 `sys.stdin.read()`，天然兼容行末多余空格、多个空行、读到 EOF 的多组数据。
4. 用到 `Decimal`（205911）、`itertools`（15128）、`functools`（16783）的都是标准库，牛客 Python 3 环境可用。
5. **不要提交 `tests/` 和 `run_all.py`**，那是本地自测用的。

## 四、这套题里最容易 WA 的地方（真实踩坑点）

- **全角/半角感叹号**（215089）：`Tacit！` 是全角 U+FF01，`No Tacit!` 是半角 U+0021，肉眼几乎看不出区别。
- **行尾空格**（22204 / 214218 / 22056 等图形题）：判题通常忽略行尾空格，但行首空格一个都不能少。
- **多组数据读到 EOF**（22204 / 22056 / 13584 / 13585）：题面没有给组数，不能用 `for T` 循环。
- **Special Judge**（204117）：输出任意一组合法解都算对，不必和样例一模一样。
- **尾随零**（200369）：`10.30` 判错，必须输出 `10.3`；整数结果不要带小数点。
- **浮点末位抖动**（205911）：`0.5` 边界上用浮点可能差 0.001，必须用精确分子 + `ROUND_HALF_UP`。
- **精度与溢出**（213397 / 16783 / 15756）：Python 天然无限精度，C++ 选手需注意 `long long`。
- **示例是占位符**（15128）：题面示例写「输入 `No_Input` / 输出 `Full arrangement of 1~8`」，
  那只是说明文字，**不能真的输出这一行**；正确输出是 40320 行全排列本身。
  这题「自测运行」必然显示答案错误（它拿占位文本当期望），要直接「保存并提交」按真实数据判题。

## 五、关于"每个种类前 5 题"的取法

题单正文的每个分类下先给一条「练习题」比赛链接，再列出该分类的题目清单。
本仓库按**正文题目清单的先后顺序**取前 5 题（这也是题单项本身的排序）。
若你所在班级的题单页面顺序与正文略有出入，按上面的**题号**对照替换即可，
`run_all.py` 是按文件名里的题号找样例的，换题只需新增 `<题号>_1.in/.out`。
